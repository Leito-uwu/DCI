# Documents

En esta carpeta se encuentran todos los **datasheets** y documentos técnicos de los componentes usados en el proyecto.

### Contenido:
- Hojas de datos del sensor TCS3200.
- Especificaciones de resistencias y capacitores.
- Pinouts de headers y conectores.

La finalidad es contar con toda la información técnica necesaria para justificar y respaldar el diseño del PCB.
