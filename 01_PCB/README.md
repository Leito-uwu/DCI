# PCB

En esta carpeta se encuentran los **esquemáticos eléctricos** y el **diseño del PCB** del proyecto.

###  Contenido:
- Esquemático del circuito con el sensor TCS3200.
- Diseño del PCB listo para edición o revisión.
- Archivos del proyecto en formato del software de diseño utilizado.

Estos archivos son la base del hardware desarrollado para el sensor.
