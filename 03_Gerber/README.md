# Gerber

En esta carpeta se encuentran los **archivos Gerber** generados a partir del diseño del PCB.

### Contenido:
- Archivos listos para ser enviados a un fabricante de PCBs.
- Incluye capas de cobre, máscara de soldadura, serigrafía, taladros y contorno.

Estos archivos son necesarios para la **fabricación física** del circuito.
